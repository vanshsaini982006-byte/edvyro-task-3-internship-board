    How it works

    1. Find a role

      Search by title, skill or city, and filter by domain and work mode.

    2. Check the details

      Open an internship to see its skills, location and number of openings.

    3. Apply in minutes

      Send your name, email and a link to your resume. A cover letter is optional.

    About this project

    Internship Board is a full-stack portfolio project built for the EdVyro Full Stack Development course: a Node.js and Express REST API, a SQLite database and a plain HTML, CSS and JavaScript front end. It is a demonstration, so the listings are sample data and it is not a real recruitment service.

    Applications are stored in a demo database that can be reset whenever the server restarts or is redeployed.

    © Internship Board demo. Data is served by the REST API at /api/internships.
